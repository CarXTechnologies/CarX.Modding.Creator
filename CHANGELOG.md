# Changelog

Лог изменений модуля. Каждый PR сопровождается записью в этом файле, новая запись — первой в своём разделе.

## [Unreleased]

### Added
- Подсказка варианта rendercore для растительности: двусторонним материалам с Alpha Clipping (RenderCoreMaterialBaker.IsFoliage) Export from material предлагает MAT_FOLIAGE_ALPHATEST (с картой нормалей) или MAT_FOLIAGE_SIMPLE_ALPHATEST (без); у подсказок зеркала появился признак isFoliage, ModRenderCoreVariants.Suggest(renderType, hasNormal, hasEmission, isFoliage) (DR3C-4465)
- Ревизия контракта варианта rendercore в документах мода: ModRenderCoreMaterial.variantRevision, строка cx_rc_rev в MTL (только для ревизии > 1), BinaryMaterial.renderCoreRevision (DR3C-4465)
- Зеркало вариантов rendercore для маркера Material: снимок RenderCoreLock.txt (enum MaterialVariant, MaterialEditorSettings, SetupMaterialVariant, Standard.shader, определения и декодирование вариантов; код rendercore не хранится — только отпечатки), ручные аннотации RenderCoreMirrorAnnotations и генерация ModRenderCoreVariantTable.g.cs из них; сборка без движка CarX.Modding.Creator.RenderCoreMirror, CLI Tools~/RenderCoreMirror (extract/check/generate/update/legacy-diff), меню ModSystem/Render Core, проверка перед сборкой игры и Validation-тест RenderCoreMirrorUpToDateTests. Изменения id, очереди, keyword'ов и свойств лечатся перегенерацией, изменения раскладки, цветового пространства, вершинных потоков и декодирования останавливают генерацию до ревью (DR3C-4465)
- Маркер Material: переопределение материала рендерера вариантом Standard-шейдера rendercore (только Binary). Таблица вариантов для карт ModRenderCoreVariants (из MaterialEditorSettings rendercore), документ ModRenderCoreMaterial (.rc.json, ссылка cx_rc в MTL, BinaryMaterial.renderCoreVariant/renderCoreResource), прокси-материалы экспорта со стабильным id (RenderCoreMaterialOverrides), Export from material из HDRP Lit / Layered Lit (RenderCoreMaterialBaker); обычный материал остаётся запасным. Описание — RenderCoreMaterial.md (DR3C-4465)
- Формат BinaryModData версии 2: длина у каждого поля, пропуск незнакомых полей, отдельный legacy-читатель версии 1, понятная ошибка на незнакомую версию (DR3C-4465)
- ModPathResolver — единое безопасное разрешение путей из данных мода внутри каталога мода (без "..", UNC и чужих абсолютных путей) (DR3C-4465)
- Тесты совместимости BinaryModData на замороженных документах v1/v2 и тесты ModPathResolver (DR3C-4465)
- ExportImporterSettings: временное изменение и восстановление настроек импорта текстур и моделей на время экспорта (DR3C-4465)

### Changed
- Прогресс загрузки мода: IModPublisher.UploadItemAsync и CreateItemAsync принимают IProgress<ModUploadProgress> (раньше IProgress<float> и без прогресса) — этап ModUploadStage (подготовка, упаковка, передача, обработка), общая доля без откатов назад и байты этапа; ModUploadProgressThrottle прореживает отчёты (смена этапа, целого процента или мебибайта, не чаще 10 раз в секунду; начало, конец подготовки и успех — без ожидания интервала). mod.io показывает настоящий прогресс упаковки и передачи модфайла через ModfileBuilder.SetUploadProgress вместо 0% до конца загрузки — только под дефайном CARX_MODDING_MODIO_UPLOAD_PROGRESS (плагин mod.io с CARX PATCH 2; ModPublishingDefines.Sync ставит и снимает его по наличию Modio.Mods.Builder.ModfileUploadProgress), без дефайна — подготовка и передача без хода до ответа mod.io, и SDK собирается с непропатченным плагином игры. Steam — прогресс SubmitAsync с этапом упаковки, в том числе при создании записи; доля 1 — только после успешного ответа площадки. ModIoPublisher.CreateItemAsync: если mod.io создал мод, но отказал в модфайле (Publish новой записи об этом не сообщает, отказ только в Results), мод удаляется так же, как в DeleteItemAsync, и возвращается отказ с id мода, причиной и итогом удаления, а не успех с модом без файла, ломающим чтение списка работ пользователя. BinaryMapPacker.Pack с Action<string, float> onProgress (с кодировкой текстур и без): ход упаковки синхронно на вызывающем потоке — по документам, перед каждой перекодируемой текстурой и по этапам; прежние перегрузки не изменились (DR3C-4465)
- ModRenderCoreVariant: vertexColors, requiredStreams, unavailableReason, revision; emission заменён свойством Emission. ModRenderCoreVariants: Offered, TryFind, Suggest, статический конструктор без исключений; TryGet возвращает только доступные варианты. Экспорт пишет каноническое имя варианта, недоступный вариант экспортируется только запасным материалом с предупреждением; хэш прокси-материала считается по свойствам, отсортированным по имени (DR3C-4465)
- Оптимизация сцены не исключает объекты с маркером Material: переопределённый материал становится отдельным сабмешем сектора (DR3C-4465)
- Оптимизация сцены при экспорте: один меш на ячейку с сабмешем на материал (вместо меша на материал×ячейку) и общие группы материалов на блок секторов; коллайдеры — свой сектор (colliderSectorSize 128 м, colliderMaxTriangles 32768) и общие файлы colliders_N вместо файла на коллайдер; куски меньше minSectorTriangles (128) переносятся в соседний сектор; уступка редактору раз в 50 мс вместо Task.Delay(1) на объект/группу; в лог — меши с LOD, сабмеши, группы и файлы коллайдеров. Формат и рантайм не менялись (DR3C-4465)
- BinaryModArchive читает ресурсы через один открытый дескриптор на время параллельных чтений (под блокировкой — только чтение блока, распаковка и CRC вне её), добавлен TryRead; CRC32 — slicing-by-8; DefaultFileProvider перепроверяет файл архива не чаще раза в секунду и с пула потоков читает синхронно (DR3C-4465)
- ModResourceFiles кэширует открытый BinaryModArchive по пути (сброс при смене файла и через ClearCache) (DR3C-4465)
- UnityGoObjExporter разнесён на отдельные классы без partial; RebuildAndSafeAll переименован в RebuildAndSaveAll, CancellationToken в RebuildAndSaveAsync — последний параметр (DR3C-4465)
- MeshExportUtility: стабильные строковые id (GUID+localFileId, для сгенерированных мешей — хэш содержимого) вместо GetHashCode; модель и .mtl перезаписываются, а не пропускаются/дописываются (DR3C-4465)
- Runtime/Publishing вынесен в Editor-only сборку CarX.Modding.Creator.Publishing; link.xml сохраняет только пространство имён формата (DR3C-4465)
- ModPublishingDefines больше не синхронизирует дефайны на загрузке домена — только из ModPublisherSession или меню ModSystem/Sync Publishing Defines (DR3C-4465)
- MetaProvider отклоняет мета-документы с незнакомой версией формата понятной ошибкой (DR3C-4465)
- Кодстайл модуля: s_/m_ для полей, табы, BinaryTexturePreparation/MtlBinaryMaterialReader/IAsyncModPacking в отдельных файлах (DR3C-4465)

### Fixed
- Альфа-тест rendercore: порог Alpha Clipping HDRP переносится в канал отсечения. Rendercore отсекает с дизерингом (texel остаётся при B − dither·0.45 − 0.15 > 0), поэтому Export from material для альфа-тест варианта пишет RenderCoreAlphaClip.ToRenderCore(альфа HDRP, порог): порог → покрытие 50%, порог ∓ min(0.05, порог, 1 − порог) → границы полосы (порог 0 или 1 — жёсткий шаг); запасной MTL альфа-теста запекает map_d так же (проход ConvertingEx CopyFourthChannelAlphaTest, суффикс _c<порог>, d = 1 при base map). Раньше сырая альфа (с Alpha Remapping min 0.296 при пороге 0.6) оставляла треть прозрачных texel'ей серыми штрихованными квадами вокруг листвы. Alpha Remapping переносится только у Transparent: у Opaque инспектор HDRP его не показывает. Маркеры, запечённые раньше, нужно перезапечь Export from material (DR3C-4465)
- Экспорт маркера Material: в документ и cx_rc_rev пишется ревизия, под которую Export from material запёк значения (RenderCoreMaterialOverride.revision), а не текущая ревизия таблицы — пересборка после обновления SDK не выдаёт старую раскладку за новую; незнакомый или недоступный вариант не пропадает молча (предупреждение один раз на запись); подсказка для альфа-теста не выбирает вариант, где AO участвует в отсечении; без карты нормалей пишется плоская нормаль; объекты MAT_LAYERS4 склеиваются оптимизацией только между собой, эмиссионным для цвета вершин считается только непрозрачный материал, как в клиенте (DR3C-4465)
- Таблица вариантов rendercore по декодированию в шейдере, а не по подсказкам: u_vThirdColor больше не получает порог Alpha Clipping HDRP (порог в шейдере rendercore фиксированный, с дизерингом; порог HDRP запекается в канал отсечения packed map — RenderCoreAlphaClip.ToRenderCore), B у MAT_ROUGHNESS_ALPHABLEND — альфа без AO, u_sTexture1 у MAT_ROAD_SIGN_EMISSION — карта эмиссии, B у MAT_COLORMASK_* — маска окраски (при экспорте 0), MAT_INTERIOR недоступен (нужен второй UV), MAT_LAYERS4 использует цвет вершин для смешивания слоёв (DR3C-4465)
- Экспорт прозрачности и Alpha Remapping HDRP Layered Lit: Surface Type Transparent пишется в .pbr.json полем surface (ModPbrSurfaceType.AlphaBlend; Blending Mode Additive/Premultiply — как Alpha с предупреждением), Alpha Remapping слоя (_AlphaRemapMin{i}/_AlphaRemapMax{i}) у прозрачного и альфа-тестового материала запекается по формуле HDRP lerp(min, max, a·_BaseColor{i}.a) в альфу копии diffuse (суффикс _a<min>_<max>[_<a>], color.a = 1), без карты — в color.a слоя; бинарный контейнер получает поле и текстуры тем же путём (DR3C-4465)
- Экспорт Double-Sided Normal Mode HDRP Lit/Layered Lit: ds 3 — Flip (раньше Flip и Mirror писались как ds 1 — Mirror), ds 1 — Mirror, ds 2 — None; BinaryMaterial.doubleSidedNormalMode (flipNormals остаётся для старых клиентов), VertexAnimationSurface.doubleSidedNormalMode для VAT; общий ModDoubleSidedNormalMode и MtlDoubleSidedCode (DR3C-4465)
- Экспорт прозрачных материалов HDRP Lit учитывает Alpha Remapping (_AlphaRemapMin/_AlphaRemapMax): ремап запекается в map_d (суффикс _a<min>_<max>[_<a>] в имени), d считается по формуле HDRP; бинарный контейнер запекает d в альфу packed map (DR3C-4465)
- Утечки Texture2D при экспорте (Blit/распаковка), материал и RT Blit освобождаются; кэш путей проверяется до Blit (DR3C-4465)
- Экспорт больше не оставляет изменёнными настройки импорта исходных ассетов и имена загруженных текстур (DR3C-4465)

### Removed
